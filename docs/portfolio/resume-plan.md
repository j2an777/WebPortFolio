# 웹 이력서와 PDF 구현 계획

승인된 방향: 기존 About Me 메인 `/`을 유지하고 `/resume`을 채용 담당자가 훑어볼 수 있는 웹 이력서로 구성하고, 상단 우측에서 동일 테마의 PDF를 내려받는다. 프로젝트 상세와 기존 경로 애니메이션은 유지한다.

## 원천 대조

- Desktop의 2025 이력서 5페이지: 텍스트 및 모든 페이지 시각 검토 완료.
- Chrome 사람인 이력서: 브라우저 런타임 연결 오류로 대조 미완료.
- Chrome 원티드 프로필: 브라우저 런타임 연결 오류로 대조 미완료.
- 최신 Purple Academy PR 근거: 기존 조사 및 병합 사례.
- PDF의 이메일 오탈자는 사용자 지정 `ha99104@gmail.com` 우선. 프로젝트 일자에 차이가 있으면 일자를 단정하지 않고 월 단위로 표현한다. 재직회사와 고객사 프로젝트를 구분한다.

## 구현 단위

1. `src/content/resume.ts`: 경력·프로젝트 요약·학력·교육·수상·연락처를 근거 기반으로 통합. 사람인·원티드 대조 후 확정.
2. `src/components/resume.tsx`: 서버 렌더링 본문과 공통 재사용 항목. 크림 배경·오렌지 강조·기존 타이포 유지, 모바일 재배치.
3. `src/app/resume/page.tsx`, header/navigation: 별도 웹 이력서 페이지와 Resume 메뉴 및 상단 PDF 다운로드. basePath와 다운로드 클릭의 경로 애니메이션 우회 적용.
4. PDF 전용 A4 템플릿: 같은 resume 데이터로 2~3페이지 생성. 본문 선택·검색·링크 가능, 한국어 폰트 포함. 생성은 빌드에 연결하고 GitHub Pages 정적 파일로 제공.
5. 검증: 데이터 연결과 PDF 경로 테스트, Pages 빌드, 320~1440 반응형·JS off·다운로드·메뉴 이동, PDF 전 페이지 렌더 확인·한글 추출·링크 확인.

## 대기 중 확정 정보

현재 회사 입사 월·정확한 재직 정보, 현재 경력 소개, 사람인·원티드의 수정 내용. 세 원천을 읽기 전에는 최종 콘텐츠를 확정하지 않는다.
